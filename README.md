## About This Project

Personal portfolio website showcasing my skills, projects, and experience as a
Java Developer and DevOps Engineer. Built with a modern full-stack architecture
and deployed with a complete CI/CD pipeline.

---

## Tech Stack

| Layer      | Technology                              |
|------------|-----------------------------------------|
| Frontend   | React 18, Vite, Tailwind CSS, Framer Motion |
| Backend    | Java 17, Spring Boot 3, REST API        |
| DevOps     | Docker, GitHub Actions, CI/CD           |
| Hosting    | Vercel (frontend) · Render (backend)    |
| Domain     | salasnorman.dev via Cloudflare          |

## Project Structure
```
portfolio/
├── frontend/    # React + Vite application
├── backend/     # Spring Boot REST API
└── .github/     # CI/CD workflows
```

## Running Locally

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Full Stack with Docker
```bash
docker-compose up --build
```
